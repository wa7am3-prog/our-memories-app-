# 💕 Our Memories - تطبيق الذكريات الخاص

تطبيق ويب فخم ومتكامل مخصص لشخصين لحفظ الصور، المنشورات، واللحظات الجميلة معاً بكل سرية وأمان.

## ✨ المميزات الأساسية
- 🔐 **نظام مصادقة آمن:** تسجيل الدخول وإنشاء حساب خاص بالشريكان فقط.
- 📸 **معرض الصور:** رفع وتصفح الصور الذكية بجودة عالية.
- 📝 **حائط المنشورات والذكريات:** مشاركة اليوميات واللحظات المميزة مع إمكانية التعليق والإعجاب.
- 🎨 **تصميم عصري (UI/UX):** واجهة مستخدم هادئة ورومانسية تدعم الوضع الليلي.

## 🚀 التقنيات المستخدمة
- **Frontend:** React.js, Tailwind CSS
- **Backend & Database:** Firebase (Auth, Firestore, Storage)
