# 💖 Our Love Story - تطبيق الذكريات والمنشورات الخاص

تطبيق ويب فخم مخصص لشخصين لمشاركة الصور، الذكريات، واللحظات الجميلة بسرية تامة بعيداً عن منصات التواصل الاجتماعي العامة.

## ✨ المميزات الرئيسية
- 🔐 **نظام مصادقة خاص:** تسجيل الدخول وإنشاء حساب مؤمن بالكامل (بدون خدمات خارجية).
- 📸 **معرض الصور والذكريات:** تصفح ورفع الصور لحفظ أجمل اللحظات.
- 💌 **حائط المنشورات:** كتابة الملاحظات واليوميات والرسائل الرومانسية.
- 🎨 **تصميم عصري (UI/UX):** واجهة مستخدم مريحة للعين مع دعم الوضع الداكن (Dark Theme).

## 🚀 التقنيات المستخدمة
- **Frontend:** React.js, Tailwind CSS, React Router
- **Backend:** Node.js, Express.js, JWT, Bcryptjs
- **Database:** MongoDB
